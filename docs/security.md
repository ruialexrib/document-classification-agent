# Segurança

- Nunca guardar credenciais no Git.
- Usar `.env` apenas localmente.
- Usar o gestor de credenciais do n8n para OAuth.
- Definir uma `N8N_ENCRYPTION_KEY` forte e persistente.
- Restringir o acesso à interface do n8n.
- Aplicar princípio do menor privilégio às credenciais Google.
- Não usar documentos reais sensíveis em exemplos ou testes.
- Rever logs e retenção de execuções.
- Manter n8n e a imagem Docker atualizados após validação.
- Executar periodicamente a auditoria de segurança do n8n.
