# Faturas de demonstração

Estes ficheiros são documentos **fictícios**, criados exclusivamente para testar o workflow n8n do projeto.

Incluem três cenários:

- `fatura_demo_agua.pdf` - serviço de água;
- `fatura_demo_eletricidade.pdf` - serviço de eletricidade;
- `fatura_demo_comunicacoes.pdf` - serviço de comunicações.

Cada PDF contém, de forma explícita:

- tipo de serviço;
- fornecedor fictício;
- número da fatura;
- número de cliente/contrato;
- data de emissão;
- data limite de pagamento;
- total a pagar;
- entidade Multibanco;
- referência Multibanco.

Não correspondem a fornecedores, clientes, contratos ou pagamentos reais.
