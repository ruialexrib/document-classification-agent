# Skill: Registar resultado

O resultado final deve ser um único objeto compatível com o schema.

O registo deve preservar:
- ID do ficheiro Google Drive;
- nome do ficheiro;
- data/hora de processamento;
- tipo e categoria;
- campos extraídos;
- confiança;
- estado;
- motivo de revisão, quando aplicável;
- versão das regras.

O registo destina-se a ser acrescentado a um Google Sheet para auditoria.
